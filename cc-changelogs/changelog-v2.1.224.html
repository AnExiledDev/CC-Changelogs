Version 2.1.224

Version 2.1.224 builds out cross-session messaging: peer sessions can now be addressed over UDS and bridge transports, held messages get approval dialogs and delivery receipts, and inbound gating adds a "coordinator" class alongside a fix that closes a path where bridge messages bypassed the gate entirely. Sandbox handling is stricter, with credential masking extended to JWTs, per-claim rules and AWS SigV4 re-signing, and blocked HTTP requests now recorded as violations with the command that caused them. Self-hosted runners become a first-class remote target: the full claude self-hosted-runner command group ships in the CLI bundle, a new --environment flag selects cloud environments, and server-supplied arguments are validated before use. Memory stores can now serve prompts directly and carry version tokens with a conflict path, while plugins can be installed from zip archives and invalid marketplace entries are dropped with an explanation instead of being accepted. On the fix side, mailbox and plan-approval writes now report failures rather than claiming success, and background remote-settings polls no longer apply across a login or logout.
