Version 2.1.227

/ultrareview and /code-review ultra now take --post and --no-post, posting a finished cloud review to a GitHub pull request as a plain comment from your own account, on by default unless remote config turns it off. Remote worker sessions now sync the working directory both ways around every turn rather than copying once at startup, a PermissionRequest hook can interrupt the whole turn by setting interrupt true on a denial, MCP connect timeouts are retried and can no longer be shortened below the global timeout by a small per-server value, workflow scripts can lock a subagent's shell to a fixed list of Bash(...) rules with bashCommandClamp, enterprise OIDC gains use_proxy for routing identity provider requests through HTTPS_PROXY, and CLAUDE_CODE_DISABLE_PRECOMPACT_SKIP forces full transcript reads after a compaction boundary. The new modelProposedGoals setting is visible in the config panel as "Claude-proposed goals" with auto, alwaysAsk and disabled, and is read only from user, policy and command-line settings, but the tool that proposes goals is behind the tengu_propose_goal flag and off in this build. Also present but switched off: device_bash, which lets a cloud session run a shell command on your own machine inside its OS sandbox, along with the per-repository sync prompt and device binding that go with it, all gated on tengu_violin_wood; the file-sending tool, moved from hard-off to the tengu_send_file flag; and the routines list_runs and get_run_log actions, which need tengu_surreal_dali plus the allow_remote_sessions and allow_routines policies.
